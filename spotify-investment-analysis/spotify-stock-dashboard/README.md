# Spotify Stock Dashboard

## Objective
Analyse Spotify's historical stock performance.

## Metrics Analysed
- Stock price
- Daily returns
- Volatility
- 50-day moving average
- 200-day moving average

## Findings
- Spotify showed strong price appreciation.
- The 50-day moving average remained above the 200-day moving average for much of the period.
- Volatility remained moderate relative to many growth stocks.

## Tools Used
- Python
- Pandas
- Matplotlib
- Yahoo Finance API
