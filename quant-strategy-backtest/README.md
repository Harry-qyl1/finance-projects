# Macroeconomic Market Analysis

## Objective

Analyse the performance of the S&P 500 and FTSE 100 using Python and historical market data.

## Skills Demonstrated

- Macroeconomic analysis
- Financial data analysis using Python
- Data visualisation
- Return and volatility analysis
- Correlation analysis

## Technologies

- Python
- Pandas
- Matplotlib
- yfinance

## Outputs

- Market performance comparison
- Annual returns
- Annual volatility
- Correlation matrix
