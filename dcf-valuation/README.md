# Spotify DCF Valuation

## Objective

Estimate Spotify's intrinsic value using a simplified Discounted Cash Flow (DCF) model.

## Skills Demonstrated

- Financial modelling
- Forecasting free cash flow
- Discounted Cash Flow valuation
- Sensitivity analysis
- Valuation assumptions

## Methodology

1. Forecasted five years of free cash flow.
2. Applied a 10% discount rate.
3. Calculated terminal value using the Gordon Growth Model.
4. Discounted all future cash flows to present value.
5. Estimated Spotify's enterprise value.

## Key Assumptions

| Assumption | Value |
|------------|------:|
| Forecast Period | 5 Years |
| Discount Rate | 10% |
| Terminal Growth Rate | 3% |

## Key Takeaways

- Spotify's valuation is highly dependent on long-term cash flow growth.
- Terminal value represents the majority of enterprise value.
- Subscriber growth and advertising monetisation remain key drivers of intrinsic value.
